# 文本切分规则

## 核心原则

### 1. 长度限制
- **目标长度**：每段约50字
- **最大长度**：不超过80字
- **语义完整**：必须是完整句子或完整语义单元
- **禁止**：切成不完整的短语

### 2. 语义完整优先
宁可稍长（60-70字），也要保证语义完整。

---

## 切分流程

### 步骤 1：预处理
- 去除多余空格和换行
- 统一标点符号
- 识别段落边界

### 步骤 2：自然分段
按以下优先级切分：
1. 按 **句号（。）
2. 按 **感叹号（！）**
3. 按 **问号（？）**
4. 按 **逗号（，）** - 仅在句子过长时
5. 按 **分号（；）**

### 步骤 3：长度检查
每段检查：
- < 30字：尝试与下一段合并（如果语义连贯）
- 30-60字：理想长度 ✓
- 60-80字：可接受 ✓
- > 80字：必须再次切分

### 步骤 4：动作分配
为每个片段分配动作：
- 根据语义选择合适的 action_id
- 避免连续相同动作
- 开头可以用 waving/nod
- 结尾可以用 thanks/waving

## 示例

### 示例 1：产品介绍

**原文：**
"欢迎体验我们全新上线的优质产品。这是一款功能强大的智能 AI 助手，致力于全方位助力日常办公，高效提升你的工作与生活效率。它搭载智能核心能力，支持多国语言实时切换，操作界面简洁清晰，上手门槛极低，全程简单易懂，人人都能轻松快速上手使用。"

**切分结果：**
```
片段 1: "欢迎体验我们全新上线的优质产品。这是一款功能强大的智能 AI 助手，致力于全方位助力日常办公，高效提升你的工作与生活效率。"
         action: waving

片段 2: "它搭载智能核心能力，支持多国语言实时切换，操作界面简洁清晰，上手门槛极低，全程简单易懂，人人都能轻松快速上手使用。"
         action: show_right
```

**原文：**
"时光流转，今日迎来 2026 年 4 月 20 日，本周的第一个工作日 —— 星期一。窗外晴空万里，万里无云，整体天气格外晴朗。空气清新舒爽，冷暖恰到好处，气温十分适宜，宜人的天气为日常出行与生活增添了满满舒适感。在这样惬意美好的时段，接下来，就让我们一同聚焦热点时事，一起来了解和关注今日各类重要的主要新闻内容"

**切分结果：**
```
片段 1: "时光流转，今日迎来 2026 年 4 月 20 日，本周的第一个工作日 —— 星期一。窗外晴空万里，万里无云，整体天气格外晴朗。"

         action: show_left

片段 3: "在这样惬意美好的时段，接下来，就让我们一同聚焦热点时事，一起来了解和关注今日各类重要的主要新闻内容"
         action: show_right
```

## 动作分配参考

### 根据内容选择动作

| 内容类型 | 推荐动作 |
|---------|---------|
| 欢迎/开场 | `waving` |
| 陈述事实 | `nod` |
| 强调重点 | `keypoints` |
| 表示赞赏 | `encourage` |
| 展示内容 | `show_left` 或 `show_right` |
| 礼貌结束 | `thanks` 或 `waving` |

### 动作连贯性

- 避免：连续3个相同动作
- 建议：每2-3个片段换一个动作
- 自然：对话场景可用 `nod` 为主
