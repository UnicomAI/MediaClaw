## 动作（Action ID）

| Action ID | 描述 | 建议触发时机 |
|-----------|------|------------|
| `encourage` | 点赞 | 强调重点、表示赞赏 |
| `keypoints` | 划重点 | 讲解关键点 |
| `nod` | 点头 | 同意、确认 |
| `show_left` | 向左侧展示 | 展示左侧内容 |
| `show_right` | 向右侧展示 | 展示右侧内容 |
| `shrug` | 摊手 | 无奈、不确定 |
| `thanks` | 拱手 | 感谢、礼貌 |
| `waving` | 挥手 | 开头或结尾 |

**动作选择建议：**
- 每个片段选择一个最符合语义的动作
- 避免频繁切换动作
- 自然对话场景可以用 `nod`
