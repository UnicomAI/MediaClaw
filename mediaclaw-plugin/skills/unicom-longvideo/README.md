# unicom-longvideo

联通元景长视频生成服务。基于 mediaclaw，通过 3 个视频镜头串联生成 9-15 秒长视频，严格保证主体一致性和动作连贯性。

⚠️ **重要：仅在用户明确提到"长视频"时使用此技能。** 普通短视频生成需求请直接使用 `mediaclaw` 的工具。

## 核心设计理念

### 三镜头串联策略

为了保证视频的连贯性，采用以下策略：

1. **主体锁定原则**：三个镜头的主体描述、场景、光影必须完全一致
2. **动作递进原则**：
   - 镜头1（起）：微小动作引入，固定镜头或极慢推镜头
   - 镜头2（承）：核心动作发生，镜头配合动作平移或跟随
   - 镜头3（合）：动作高潮或收尾，镜头拉开展示全貌或特写定格
3. **尾帧衔接原则**：使用前一个镜头的最后一帧作为下一个镜头的起始帧
4. **运镜连续性原则**：运镜必须保持方向和速度的连贯性，避免突变
5. **动作连续性原则**：动作必须从上一镜头的结束状态自然延续，避免状态突变

### 分镜提示词设计

分镜提示词格式统一为：
```
[锁定主体描述]，[锁定场景]，[锁定光影]，[动态动作描述]，[运镜描述]
```

**示例：**
- 镜头1：`一只可爱的橘猫，阳光明媚的花园，午后柔和光线，慵懒地眨了眨眼睛，固定镜头`
- 镜头2：`一只可爱的橘猫，阳光明媚的花园，午后柔和光线，慢慢地站起身子伸懒腰，镜头缓慢跟随`
- 镜头3：`一只可爱的橘猫，阳光明媚的花园，午后柔和光线，欢快地向前奔跑，镜头拉开展示全貌`

**关键：前三个部分（主体、场景、光影）在三个镜头中必须字毫不差、完全一致！运镜必须遵循连续性原则！动作必须从上一镜头结束状态自然延续！**

## 输出目录规则

所有生成结果必须写入同一个统一根目录 `{task_id}/`：
- 如果用户指定了保存目录，则根目录为 `{用户指定目录}/{task_id}/`；
- 如果用户未指定目录，则根目录为 `workspace/unicom-longvideo/{task_id}/`。

根目录下使用固定文件名，避免路径混乱：
- `shot1.mp4`
- `shot1_last_frame.jpg`
- `shot2.mp4`
- `shot2_last_frame.jpg`
- `shot3.mp4`
- `final.mp4`
- `manifest.json`

## 使用方法

详细使用指南请参考 [SKILL.md](./SKILL.md)。

### 简要流程

1. **生成分镜脚本** - 使用 LLM 或 `mediaclaw_image_qa` 生成 3 个连贯分镜
2. **生成第一个镜头** - 文生图 + 图生视频
3. **生成第二个镜头** - 提取前一镜头尾帧 + 图生视频（ + 润色分镜）
4. **生成第三个镜头** - 提取前一镜头尾帧 + 图生视频（ + 润色分镜）
5. **拼接视频** - 使用 ffmpeg 拼接三个镜头

### 前置要求

- `mediaclaw` 工具 已配置并可用
- `ffmpeg` 已安装（用于视频拼接和帧提取）
